Responsive Design Principles

Fluid Layouts

Use flexible widths so content fits the available space.

.container {
  width: 90%;
  max-width: 1200px;
}

Flexible Media

Keep images inside their containers without stretching them.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Change the layout when the screen becomes narrower.

@media (max-width: 600px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
