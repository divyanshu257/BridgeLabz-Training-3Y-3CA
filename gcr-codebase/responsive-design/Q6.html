Responsive CSS Cheat Sheet

Filters

Change an image's appearance using filter: grayscale(100%);

Media Queries

Apply styles at a breakpoint using @media (max-width: 700px).

Responsive Design

Build layouts that adapt to different screen sizes.

Typography

Align items using display: flex;
